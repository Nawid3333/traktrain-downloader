## Highlights

- **No more urllib.parse**: httpx.URL percent-encodes paths itself, so artist slugs with spaces or unicode work without the legacy import.
- **Blank-page hardening**: empty pagination pages now return no tracks instead of crashing lxml.
- **Safer downloads**: partial files are deleted immediately on a failed attempt, so a broken download can never pose as "already downloaded" on the next run.
- **Windows-safe filenames**: reserved device names (CON, COM1, LPT1, ...) now get an underscore suffix instead of failing silently.
- **Cleaner failures**: scraping problems raise a typed `ScrapeError` and are reported without a traceback.
- **Robust input**: accepts bare slugs, full profile URLs and stray slashes; an empty song query no longer matches the first track.
- **40 offline tests** (was 30), ruff-clean, verified against the live site.
